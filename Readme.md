# Video Game Recommendation MSc Dissertation

MSc Data Science dissertation project developed at the University of Bristol.

This repository contains the implementation, evaluation and supporting data for a query-driven hybrid video game recommendation system.

## Main Components

- Weighted Metadata Recommender
- Rich-Text TF-IDF Recommender
- Transformer-Based Semantic Recommender
- Graph-Based Recommender
- Weighted Reciprocal Rank Fusion Hybrid
- Hardware Requirement Enrichment
- Evaluation and Sensitivity Analysis
