# Dataset

The dataset used in this project is based on the **Steam Games Dataset 2025** from Kaggle.

Source dataset:
`games_march2025_cleaned.csv`

The dissertation preprocessing pipeline is implemented in:

`notebooks/01_Data_Preparation.ipynb`

This produces the processed dataset used by the recommendation models:

`games_clean_v1.csv`  
Shape: **89,618 × 50**

The dataset files are not included in this repository due to their large size.

Processed dataset:
[Google Drive link]

To reproduce the dataset, download the original Kaggle dataset and run the data preparation notebook.
